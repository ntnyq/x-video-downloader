基于当前仓库功能的设计提案，2026-10-12。

本次交付设计图与可点击的 HTML 预览，未替换生产 Vue 页面。预览使用示例数据和原生 HTML 控件模拟组件外观；下载、存储、任务控制均不调用扩展 API。X 页面、视频播放器与日期也都是示意内容。

## 设计取舍

- 保留默认黑白灰。主下载动作使用实心按钮；普通操作使用轻量图标；强调色只用于按钮、选中态和进度。
- 将三层重复下载入口合并成视频行的单条下载和底部批量下载。仅一个视频的帖子视图隐藏行内下载按钮，保留底部主按钮。
- 保留页面级、帖子级、视频级勾选。全选支持部分选中；取消全选等价于清空选择。零选择时禁用批量下载。HLS 不参与勾选。
- 默认显示作者、单行帖子摘要、视频序号与画质。长帖子可在原帖查看；完整文件名、帖子 ID 放进下载详情。画质展开时保留完整分辨率、码率、最高画质标记。
- 视频页的任务信息应就近附在对应视频下方，或用短反馈指向下载记录，避免在列表上方重复整组进度。
- 下载记录中保留搜索、作者筛选、暂停、继续、取消、重试、移除。错误提供下一步；状态不单靠颜色区分。
- 设置顺序改成下载、文件名、外观、帮助。欢迎页不再渲染整份设置表单。
- 文件名模板仍需显式保存；其他偏好自动保存。恢复默认仅改草稿，点击保存后生效。设计中的短模板是用户自定义示例，现有默认模板不变。
- 当前数据没有封面、时长和下载前大小，因此列表不设计这些字段。下载记录的大小仅使用浏览器已提供的字节数；未知大小不显示虚构百分比。

## 为什么继续使用 shadcn-vue

现有价值是可访问的交互行为、统一主题变量和已经适配的 Shadow DOM 弹层，不是默认卡片或大圆角的外观。布局简化与保留组件体系相容。

| 能力                     | 组件与实现约束                                                    |
| ------------------------ | ----------------------------------------------------------------- |
| 主次动作和图标操作       | 复用 `Button`；图标统一 `@lucide/vue`，不再把 ↓ 写进翻译          |
| 页面视频 / 下载记录      | 复用 `Tabs`，保留键盘切换、选中态与对应面板语义                   |
| 画质、并发、作者筛选     | 复用 `Select`；触发器紧凑，菜单提供完整信息                       |
| 批量选择                 | 复用 `Checkbox`，保留不确定态、禁用状态和名称                     |
| 保存位置                 | 复用 `Switch` 和可点击 `Label`                                    |
| 文件名、自定义 RGB、搜索 | 复用 `Input`；填写 `name`、标签、错误关联及自动完成策略           |
| 任务状态                 | 复用 `Progress`；未知总量时不显示假百分比                         |
| 保存成功、加入队列       | 复用 `Sonner`，短反馈，不挤占内容区域                             |
| 长文件名详情、低频帮助   | 拟按需新增 `Collapsible`；不为静态分区添加组件依赖                |
| 清理确认                 | 拟新增 `AlertDialog`；说明只移除记录、保留文件，不清理活动任务    |
| 纯图标提示               | 拟按需新增 `Tooltip`，同时保留 `aria-label`；不能只靠悬停可见信息 |

继续使用 `useOverlayTarget` 与现有 `SelectContent` 的 Shadow Root 挂载位置。下拉框内的 Esc 只关闭下拉框；第二次 Esc 才关闭页内面板并归还焦点。不将外部弹层直接挂到 X 页面的 `document.body`。

## 布局和交互规格

| 项目 | 规格                                                                                   |
| ---- | -------------------------------------------------------------------------------------- |
| 浅色 | 背景 `#ffffff`、次级表面 `#f5f6f7`、文字 `#0f1419`、次级文字 `#596570`、分隔 `#e5e8eb` |
| 深色 | 沿用仓库黑色背景和深灰表面；X 的 dim 模式继续使用其独立主题变量                        |
| 字体 | 系统 UI 字体；中文优先 PingFang SC，无远程字体依赖                                     |
| 文字 | 面板标题 14px；主要控制 12–13px；辅助信息 11–12px；数据对齐使用等宽数字                |
| 尺寸 | 弹窗宽 360px、最多 600px 高；单视频页内面板随内容收缩；设置正文约 544px 宽             |
| 圆角 | 控件 7–8px，面板 16px；仅浮层使用阴影                                                  |
| 层级 | 标题固定、内容可滚动、批量动作固定底部，三者互不覆盖                                   |
| 图标 | 16–20px，常规按钮点击范围至少 32px；触摸环境扩大到 44px                                |
| 焦点 | 2px 可见描边；所有图标按钮有名称；选择器和复选框可通过键盘操作                         |
| 反馈 | 成功用简短 toast；失败用邻近的持久错误；表单错误关联输入框并转移焦点                   |

面板重新布局仍应保留现有最大批量限制和全部选项，不得通过裁剪选择来静默提交。保存位置询问开启且选中多个视频时，仅在提交处显示「需逐个确认保存位置」。

下载生命周期：下载中提供暂停/取消，等待中提供暂停/取消，暂停提供继续/取消，失败、取消、记录移除提供重试/移除，完成提供移除。清理范围以当前搜索与作者筛选为准。无匹配与无历史分开提示。

所有五种语言沿用现有国际化机制。生产落地需验证英文和德式长文件名等极长文本；日期和数量使用 `Intl`。中文设计稿中的日期、数量仅为固定示例。

## 验证范围

设计稿通过本地浏览器渲染并导出 PNG。检查桌面与 320px 视口的横向溢出、图标名称、选中计数、筛选和清理对话框；记录详见 [validation.md](./validation.md)。

这不是生产扩展的 X 或 Firefox 实测。预览的原生选择器和对话框不等于 Reka UI 的最终键盘与 Shadow DOM 行为；落地后需在真实 popup/content 环境重新验证。未新增权限、下载服务或数据采集。
